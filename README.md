# Curso de Engenharia de Dados - Python

Exercícios práticos do curso, organizados por módulo.

## Módulo 1
- Exercício 1: Análise de despesas por categoria e ano (pandas)
- Exercício 2: Controle de estoque (dicionários)
- Exercício 3: Arquitetura de armazenamento de dados (SQLite)

## Como rodar
1. Crie um ambiente virtual: `python -m venv venv`
2. Ative: `venv\Scripts\activate`
3. Instale as dependências: `pip install pandas`
4. Rode o script desejado: `python nome_do_arquivo.py`
